═══════════════════════════════════════════════════════════════
❌ ПРОБЛЕМА:
═══════════════════════════════════════════════════════════════

При затисканні стрілки `InvalidateVisual()` викликався **ДЕСЯТКИ РАЗІВ НА СЕКУНДУ**:

```
Клавіатура Windows: Key Repeat Rate ≈ 30 разів/секунду
↓
Window_PreviewKeyDown викликається 30 разів/секунду
↓
MainMap.InvalidateVisual() викликається 30 разів/секунду
↓
ПОВНИЙ рендеринг карти 30 разів/секунду (тайли, маркери, зони)
↓
Навантаження на CPU: 🔥🔥🔥 ДУЖЕ ВИСОКЕ!
```

**Результат:**
- ❌ Lag під час обертання
- ❌ Високе навантаження на CPU
- ❌ Марні ресурси (людське око бачить max 60 FPS)

═══════════════════════════════════════════════════════════════
✅ РІШЕННЯ: ТРОТЛИНГ (60 FPS LIMIT)
═══════════════════════════════════════════════════════════════

Обмежуємо частоту перемальовування до **60 FPS** (16ms між кадрами):

```csharp
// Throttling поля
private DispatcherTimer _invalidateTimer;
private bool _needsInvalidate = false;
private DateTime _lastInvalidateTime = DateTime.MinValue;
private const int InvalidateThrottleMs = 16; // 60 FPS

// Замість MainMap.InvalidateVisual()
private void InvalidateThrottled()
{
    var now = DateTime.Now;
    var timeSinceLastInvalidate = (now - _lastInvalidateTime).TotalMilliseconds;

    if (timeSinceLastInvalidate >= InvalidateThrottleMs)
    {
        // Достатньо часу пройшло - малюємо одразу
        MainMap.InvalidateVisual();
        _lastInvalidateTime = now;
        _needsInvalidate = false;
    }
    else
    {
        // Занадто рано - запланувати на пізніше
        _needsInvalidate = true;
        
        if (_invalidateTimer == null)
        {
            _invalidateTimer = new DispatcherTimer();
            _invalidateTimer.Interval = TimeSpan.FromMilliseconds(InvalidateThrottleMs);
            _invalidateTimer.Tick += (s, e) =>
            {
                if (_needsInvalidate)
                {
                    MainMap.InvalidateVisual();
                    _lastInvalidateTime = DateTime.Now;
                    _needsInvalidate = false;
                }
                _invalidateTimer.Stop();
            };
        }

        if (!_invalidateTimer.IsEnabled)
        {
            _invalidateTimer.Start();
        }
    }
}
```

↓
Рендеринг: 60 × 2-5ms = 120-300ms на секунду CPU часу

**Результат:**
- ✅ 60 FPS (ідеально для людського ока!)
