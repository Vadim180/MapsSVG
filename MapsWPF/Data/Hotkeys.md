# Hotkeys and Controls

This document lists all available keyboard shortcuts and mouse interactions for the MapsWPF application.

## Mouse Controls

| Action | Control | Description |
| :--- | :--- | :--- |
| **Pan Map** | **Left Click + Drag** | Drag the map to move around. |
| **Zoom Map** | **Mouse Wheel** | Scroll up to zoom in, scroll down to zoom out. |
| **Set Target** | **Right Click** | Places the red target marker at the cursor location. |
| **Move Target** | **Right Click + Drag** / **Right Hold + Move** | Dragging with the right mouse button moves the target marker in real-time. |
| **Delete Target** | **Left Double-Click on Marker** | Double-clicking the red target marker deletes it. |
| **Set Attack Center** | **Ctrl + Shift + Double Left Click** | Sets the center of the attack zone (HUD center) to the clicked location. |
| **Rotate Attack Ray** | **Alt + Mouse Move** | Rotates the attack ray to face the mouse cursor while Alt is held down. |

## Keyboard Shortcuts

### Navigation
| Key | Action |
| :--- | :--- |
| **W, A, S, D** | Pan the map (Up, Left, Down, Right). |


### Attack Zone Controls
| Key | Action |
| :--- | :--- |
| **Up Arrow** | Increase Attack Radius (Sector Radius). |
| **Down Arrow** | Decrease Attack Radius. |
| **Left Arrow** | Rotate Attack Zone Counter-Clockwise (Left). |
| **Right Arrow** | Rotate Attack Zone Clockwise (Right). |
| **Shift + Left Arrow** | Shift entire zone Counter-Clockwise (Rotate Shift). |
| **Shift + Right Arrow** | Shift entire zone Clockwise (Rotate Shift). |
| **Q** | Rotate Map Bearing Clockwise. |
| **E** | Rotate Map Bearing Counter-Clockwise. |
| **Z** | Clear all markers (Keyboard command). |

## UI Controls
*   **Go GroupBox**: Enter City name and click "Search" or "Go" to fly to location. Use "Zoom Center" to focus on markers.
*   **Attack Settings**: Manually enter Angle, Radius, Width in the text boxes.
*   **Distance**: Displayed in the left panel and on the top-right map overlay when a target is set.
