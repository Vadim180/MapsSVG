# Map Limits — звіт змін ✅

## Коротко
Додано підтримку обмеження руху карти (Map Limits) при перетягуванні мишкою та при панінгу через клавіші W/A/S/D. Обмеження застосовуються в реальному часі — карта не може вийти за межі прямокутника, заданого Top-Left / Bottom-Right.

---

## Змінені файли 📁

- **GMap.NET/GMap.NET.Core/Internals/Core.cs**
  - Метод `Drag(GPoint pt)` — додано перевірку `BoundsOfMap` під час drag і корекцію `RenderOffset`/ `_dragPoint`, щоб позиція не виходила за межі.
  - Метод `DragOffset(GPoint offset)` — аналогічна перевірка для переміщення через `Offset()` (WASD / програмний pan).
  - Логіка використовує `FromLocalToLatLng(Width/2, Height/2)` для тестування майбутньої центральної позиції і `Provider.Projection.FromLatLngToPixel(...)` для підгонки pixel offset при обрізанні до кордонів.

- **GMap.NET/GMap.NET.WindowsPresentation/GMapControl.cs**
  - `BoundsOfMap` змінено на властивість з сеттером, який синхронізує значення з `_core.BoundsOfMap`.

- **MapsWPF/MainWindow.xaml.cs**
  - Додано `UpdateBoundsOfMap()` — читає налаштування (TopLeft/BottomRight + вкл. чекбокс) і встановлює `MainMap.BoundsOfMap`.
  - Реалізовано `CheckMapLimits(PointLatLng point)` — допоміжна фунція для клепання/переміщення `MainMap.Position` у межі (викликається на OnPositionChanged та при завданні лімітів).
  - Оновлено обробники UI: `CheckBoxLimitMap_Checked/Unchecked`, `TextBoxLimitTopLeft_TextChanged`, `TextBoxLimitBottomRight_TextChanged` — тепер викликають `UpdateBoundsOfMap()`.
  - Ініціалізовано виклик `UpdateBoundsOfMap()` при завантаженні вікна.

## Поведінка / деталі реалізації 🔧

- При drag (`Core.Drag`) або при програмному offset (`DragOffset`) обчислюється `testPosition` для потенційного центру карти. Якщо `testPosition` виходить за `BoundsOfMap`, позиція заокруглюється (clamped) до меж і обчислюється відповідний `RenderOffset` у пікселях, щоб візуально карта зупинилась на краю.

- `BoundsOfMap` задається як `RectLatLng.FromLTRB(leftLng, topLat, rightLng, bottomLat)` у `MainWindow.UpdateBoundsOfMap()`.

- Перевірки виконуються в реальному часі (не тільки після завершення drag), що запобігає «виходам» карти за межі під час перетягування.

## Як користуватись (UI) 💡

1. Відкрити `Expander → Map Limits` у вікні налаштувань.
2. Включити `Enable Limits` (чекбокс).
3. Ввести координати: `Top Left (Lat,Lng)` та `Bottom Right (Lat,Lng)`.
4. Обмеження застосуються одразу та збережуться у налаштуваннях (викликається при завантаженні).

## Тестування ✅

- Проект зібраний локально: `dotnet build` — збірка успішна (0 помилок, є стандартні попередження).
- Рекомендації для ручного тестування:
  - Перетягувати карту мишкою в різні напрямки до меж.
  - Панити через WASD/стрілки (Zoom/Rotation не повинні порушувати обмеження).
  - Перевірити кейс при повороті карти (Bearing) і при різних zoom рівнях.

## Обмеження та потенційні поліпшення ⚠️

- Поточна логіка клепання підраховує положення через проекцію і може мати невеликі огріхи при дуже великих zoom або біля полюсів.
- Варто додати візуалізацію прямокутника лімітів на карті (шар/маркер), щоб користувач бачив кордони.
- Необхідно протестувати випадок з перетином 180° меридіану (antimeridian wrap).
- Можна додати плавне «уповільнення» при наближенні до краю замість миттєвого залипання.
- Додати unit/integration тести для `Core.Drag`/`DragOffset` з емульованими входами.
