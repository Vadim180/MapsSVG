### 2.5 Розрахунок пікселів з метрів

```csharp
private double GetPixelDistance(PointLatLng center, double meters)
{
    // Конвертує метри в пікселі на основі поточного zoom
    var p1 = FromLatLngToLocal(center);
    var offsetPoint = DestPoint(center, 90, meters / 1000.0);
    var p2 = FromLatLngToLocal(offsetPoint);
    return Math.Sqrt((p1.X - p2.X)² + (p1.Y - p2.Y)²);
}
```

## 4. Оптимізації продуктивності GMap.NET

### 4.1 Throttling для Drag Operations

**Файл:** `GMap.NET/GMap.NET.Core/Internals/Core.cs`

**Проблема:** При перетягуванні карти `UpdateBounds()` викликався занадто часто (~140ms кожен виклик), що створювало lag.

**Рішення:** Throttling mechanism:

```csharp
private const int UPDATE_BOUNDS_THROTTLE_MS = 150;
private DateTime _lastUpdateBoundsTime = DateTime.MinValue;
private GPoint _pendingCenterTileUpdate = GPoint.Empty;

public int UpdateBoundsThrottleMs { get; set; } = 150;
```

**Логіка:**
1. Під час drag: `UpdateBounds` викликається максимум раз на 150ms
2. Пропущені оновлення зберігаються як "pending"
3. При `EndDrag()` виконуються всі відкладені оновлення

**Результат:**
| Операція | До | Після |
|----------|-----|-------|
| Перший Drag | 135-170ms | 28-38ms |
| Звичайний Drag | 28-38ms | 0-5ms |

### 4.2 MouseWheel Zoom Debouncing

**Файл:** `GMap.NET/GMap.NET.WindowsPresentation/GMapControl.cs`

**Проблема:** При скролі виконувалось 3-4 zoom підряд за 100ms, кожен завантажував 45 нових тайлів.

**Рішення:** Debouncing з накопиченням delta:

```csharp
private DispatcherTimer _zoomDebounceTimer;
private int _pendingZoomDelta = 0;
// Interval: 100ms
```

**Логіка:**
1. MouseWheel події накопичують delta
2. Таймер перезапускається при кожному event
3. Після паузи 100ms — один zoom з накопиченим delta

**Результат:**
| Метрика | До | Після |
|---------|-----|-------|
| Zoom операцій при скролі | 3-4 | 1 |
| Час zoom | 4000-6000ms | 200-500ms |

### 4.3 Tile Buffer в TileMatrix

**Файл:** `GMap.NET/GMap.NET.Core/Internals/TileMatrix.cs`

**Проблема:** При drag назад тайли перезавантажувались з мережі.

**Рішення:** Буферизація +100 тайлів понад видимих:

```csharp
public int MaxTilesPerLevelBeyondVisible { get; set; } = 100;
```

**Результат:** Drag назад — 0ms замість 2000-4000ms.
